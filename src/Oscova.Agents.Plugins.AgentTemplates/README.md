# Agent Templates

Eight editable starters for research, study, interview practice, writing, documents, meetings, planning and email.

The plugin contributes metadata, requested tools and English instructions through `AgentPluginBuilder.AddAgentTemplate`. It has no runtime package dependencies and does not create agents by itself.

Oscova bundles this plugin with its .NET tool. Browse its templates from Agents settings. The plugin declares tools and an optional picture key. The Host resolves these against available tools and seed assets using the same rules for every plugin. Disabling or removing the plugin takes effect after restart and preserves existing agent copies.

The instruction wording is original Oscova content. Source research and upstream reference material are not included in this package.
