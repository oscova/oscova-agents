# Backup

Create a protected backup, or open the separate reset dialog when you need a clean environment.

- **Export** opens the encrypted backup dialog.
- **Reset Environment** opens the operator-only reset confirmation.
- Restore is available from **Operator Setup** before any user exists.
- Keep an exported backup and its passphrase safely.

> **Note:** Export Passphrase, Account Password, and Vault Password serve different purposes.

> **Note:** CLI updates retain the application data. Create a backup before updating in case the data format changes.
