# Create user

Create a regular account and set its initial sign-in password.

- Enter **Full name**, **Username**, and **Email**.
- Full name cannot be empty. Usernames use lowercase and need at least 3 characters.
- Enter **Password** with at least 6 characters and a matching **Confirm password**.
- Click **Create user** and correct any reported account validation error.
- **Cancel** returns without creating the account.

> **Note:** This sets the Account Password. The user creates their own Vault Password at first sign-in.
