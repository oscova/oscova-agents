# Find skills online

Search the configured repositories and install a skill into your account.

- Discovery uses GitHub metadata by default, with cached results reused for one hour.
- The operator can enable full repository downloads in **Manage sources**.
- Source preparation shows repository, branch, status, and progress where totals are known.
- Search by name as soon as results arrive.
- **Details** loads only the selected skill description.
- **Install** downloads the selected skill's files into your account.
- **Install** becomes available after installed skills have been checked.
- Already installed skills cannot be installed again here.
- Installation progress and failures appear beneath the result.
- Assign the installed skill to an agent separately.

> **Note:** Closing cancels pending source preparation. Reopen to retry. Cached results remain available if a source update fails.

> **Note:** Installed skills may include scripts. Discovery does not verify that a skill is safe.
