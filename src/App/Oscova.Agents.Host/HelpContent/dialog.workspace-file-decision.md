# Unsaved workspace changes

Choose what happens to your file edits before leaving their current scope or closing a dirty document.

- **Save** writes the pending edits before continuing.
- **Discard** removes the pending edits without writing them.
- **Cancel** keeps the document and draft open.
- If the file changed elsewhere, **Overwrite with my edits** replaces its latest contents with your draft.
- **Reload latest** asks for confirmation before replacing your draft with the current file.

> **Note:** A failed save keeps the draft. If several files need saving, earlier successful saves remain written.
