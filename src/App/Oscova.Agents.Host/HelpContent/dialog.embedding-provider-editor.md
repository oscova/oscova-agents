# Configure embedding provider

Connect the model used to index memory and search your Library.

> **In plain terms:** embeddings turn text into numbers so related material can be found.

- Choose **Provider Type**, then enter **Provider Name** and **Model ID**.
- Enter a valid **Base URL** when overriding the endpoint.
- Set positive **Vector Dimensions** matching the model's output.
- Select a **Saved API Key** when authentication is required.
- Change **Endpoint scope** only to match the endpoint's actual network location.
- **Save** applies the provider, while **Cancel** discards edits.

> **Note:** Changing the embedding model or dimensions clears the existing memory index so Oscova can rebuild it.
