# Task run scope

Replace the selected agent's runtime settings for this task only.

- **Enable Compaction** summarizes conversation history near the context limit.
- **Enable Memory** allows saved memory to enter context and be saved or retrieved.
- **Enable Task List** lets the agent track multi-step work.
- **Use subagents** lets the agent hand independent tasks to separate instances of itself. The run finishes after they finish.
- **Local only** blocks cloud providers and internet tools.
- **Tool discovery** exposes pinned tools first and lets the agent find others.
- Select **Allowed Tools**, **Agent Tools**, and **Skills**.
- Choose the server **Workspace Folders** the task may access.
- **Save** updates the task editor's scope draft.
- **Cancel** discards these scope edits.

> **Note:** Save the task editor separately to keep this scope. It does not change the selected agent.
