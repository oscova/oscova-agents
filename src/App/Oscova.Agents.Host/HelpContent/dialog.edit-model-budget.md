# Set model budget

Set estimated spending limits for this provider.

- Enter a positive **Daily limit (USD)** or **Monthly limit (USD)**.
- Leave a limit blank for no limit.
- **Notify me at 80% of a limit** enables a notice once per budget period.
- Click **Save** to apply the limits.
- **Cancel** preserves the existing policy.

> **Note:** Shared providers have one combined budget across consumers. Periods follow the provider owner's timezone.
