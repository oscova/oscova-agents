# Task runs

Review the saved execution history for one task.

- Compare each run's **Status**, **Started**, **Completed**, and **Summary**.
- **Inspect session**, when available, opens its recorded messages.
- An empty list means no runs have been recorded.
- The trash button deletes a finished run and its transcript after you confirm. The newest finished run and a running one have no trash button, because the newest finished run sets the next scheduled time.
- **Keep last runs** in the task editor deletes older runs automatically.

> **Note:** Inspecting a session does not rerun the task.
