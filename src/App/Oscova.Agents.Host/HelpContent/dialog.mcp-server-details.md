# MCP server details

Inspect one server's saved configuration.

- Review **Name**, **Transport**, and **Network use**.
- HTTP details show the endpoint and saved headers.
- STDIO details show the execution environment, command, arguments, working directory, and environment entries.
- **Configured** means required fields exist.
- **Incomplete** means configuration still needs correction.

> **Note:** Configured is not a connection test. Saved literal secrets may be visible here, while resolved environment values are not shown.
