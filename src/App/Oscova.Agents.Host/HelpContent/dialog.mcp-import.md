# Import MCP configuration

Paste a server configuration instead of entering each connection by hand.

- Paste JSON in VS Code, Cursor, or Claude Desktop format.
- Click **Import** to read the servers.
- Regular users choose an enrolled **Device** in the editor for each imported STDIO server before saving.
- Correct invalid JSON or an empty server list before retrying.
- **Cancel** discards the pasted configuration.

> **Note:** Imported configurations still need valid endpoints or commands and a successful connection before their tools are usable.
