# Edit file

Change the selected file's text and save it back to its current location.

- Edit the text in the code editor.
- **Save** writes the contents and closes the dialog after success.
- **Cancel** closes without saving your edits.
- **History**, when available, opens the file's restore points.
- A failed save leaves the dialog open with its error.
- Memory and private-note indexes are derived. Edit a concept to update them.

> **Note:** Files edited through Files settings must stay within 512 KB.

> **Note:** Saving a `.enc` file encrypts it automatically, including a file that previously contained plaintext. Saving a managed definition applies its change immediately.

> **Note:** An encrypted file protected by a different key does not open. The editor shows why, and the file stays unchanged.
