# Application Logs

Records fit the dialog width and become labelled groups on narrow screens. Expand a record to read its full details.

The logs dialog helps you browse log files, filter entries, inspect details, export results, and clear a selected log.

> **In plain terms:** logs are records of app activity, warnings, and errors.

## Find and inspect entries

- Admins can choose **Mine**, **System**, or **User...** scope.
- For **User...**, enter a valid user GUID and press **Enter**.
- Choose a severity and log file.
- Type in **Search logs...** and press **Enter**.
- Click **Refresh** to reload available files and entries.
- **Original JSON Lines** downloads the complete selected file.
- **Filtered text** and **Filtered CSV** export all matching entries from the newest 50,000 valid lines.
- Expand rows with metadata or exception details.
- Use page buttons when more than 100 entries match.

> **Note:** the dialog has no copy action. Logs can contain sensitive values, so review exports before sharing them.

## Clear safely

- Click **Clear**, then confirm, to erase the selected log file.
- Use **Export → Original JSON Lines** before clearing a file that must be preserved.

> **Note:** clearing cannot be undone.
