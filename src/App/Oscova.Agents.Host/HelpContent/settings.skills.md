# Skills


Installed skills adapt to the available width, with labelled groups on narrow screens.

Skills manages imported skill packages and how their bundled scripts may run. Import skills here, then assign them to agents.

## Import and manage skills

- The operator can toggle **Share with users** to copy a skill into user accounts. **Update for users** publishes later edits. Turning sharing off removes managed copies.
- Existing personal skills with the same name are kept. Sharing reports how many copies changed and how many personal copies were preserved.
- Shared copies show **Managed by operator**. The built-in guide shows **Included for all users** and needs no sharing action.

- **Find skills online** searches the repositories set under **Manage sources**.
- The operator chooses the host's search method under **Manage sources**.
- Assign imported skills to an agent before expecting it to use them.
- Agent-requested installs or authored skills require approval.
- After approval, newly assigned skills become available when you send your next message.
- Use the delete icon to uninstall a skill from all assigned agents.
- If uninstall fails, correct the reported problem and retry.

> **Note:** Oscova restores its built-in product guide and main-agent assignment at startup, replacing local edits or deletion.

> **Note:** Choose where bundled scripts run under [Execution](settings.execution.md).
