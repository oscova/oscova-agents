# Find MCP servers online

Find a server in the official MCP Registry and choose how to configure it.

- Enter a search and click **Search**, or press Enter.
- Review the server description, **Website**, and **Repository**.
- Choose an available setup method.
- **Add** opens that configuration in the server editor for review.
- A manual-only result requires setup outside this picker.

> **Note:** A registry listing does not establish trust. Review the endpoint or program before saving.
