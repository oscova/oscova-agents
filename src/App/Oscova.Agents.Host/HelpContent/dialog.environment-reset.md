# Reset environment

Start again from Operator Setup by moving the current environment into a retained sibling directory.

- Finish important work and stop external writers first.
- Stop Avatar MCP with `oscova avatar mcp stop`.
- Type `RESET` exactly to enable **Reset Environment**.
- Reset moves users, chats, settings, files, credentials, plugins, keys, and the database.
- Models, voices, shared system logs, CLI files, the installed tool, and Avatar files stay in place.
- Everyone is signed out and default plugins are installed again.
- The current address remains available for setup.
- Reconfigure network settings for later restarts.
- **Cancel** returns without resetting.

> **Note:** The retained directory is private, but is not an encrypted backup. Create an export beforehand if needed.

> **Note:** If acceptance is uncertain, do not retry. Reopen Oscova and follow the reported offline recovery guidance.
