# Plugin details

Review an installed plugin's identity, current status, and diagnostics.

- Check **Name**, **Plugin ID**, **Version**, **Assembly**, and **Entry Type**.
- **Current Status** describes the running installation.
- **Load On Next Restart** describes its saved activation choice.
- Read **Diagnostic** when a plugin cannot load.
- Model-plugin hardware advice separates declared requirements, detected hardware and runtime verification. A detected NVIDIA GPU does not prove CUDA libraries load. Test a saved model provider to verify inference.

> **Note:** This view changes no activation settings. Enabled plugins run trusted code inside Oscova.
