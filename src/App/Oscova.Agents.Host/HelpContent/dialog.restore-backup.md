# Restore backup

Restore an encrypted backup on a fresh installation before any account exists.

- **Choose backup file** accepts a `.oscb` file up to 500 MB.
- Enter the original **Backup passphrase**.
- **Show password** reveals the entered passphrase.
- Click **Restore backup**, then keep the window open during restart preparation.
- **Cancel** returns without restoring.

> **Note:** Expanded content must fit within 2 GB. Unsupported backup formats are rejected.

> **Note:** Keep the original backup until you verify restored data. Every imported user still needs their own Vault Password.

> **Note:** If startup stops during restore, follow the reported offline recovery instructions for that exact environment.
