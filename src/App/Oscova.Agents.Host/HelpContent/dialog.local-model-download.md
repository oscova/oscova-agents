# Download GGUF model

Follow a local model download from the URL selected in the provider editor.

- The download address must use HTTP or HTTPS.
- Review the progress and any reported error.
- **Cancel** stops the download attempt.
- **OK** closes the dialog when it finishes or fails.
- Return to the provider editor to select the downloaded model and save the provider.
- Download completion does not prove memory fit or native runtime availability. Review the editor's estimate, save, then use the provider row's **Test** action.

> **Note:** An already-present destination file is reused.
