# General

Set your chat preferences, language and battery protection here, and review versions or remove saved conversations.

> **In plain terms:** these preferences belong to your account.

## Set preferences

- **Customization** saves **Light**, **Dark** or default **System** in this browser, with **System** following your device.
- **Reset** restores appearance defaults, including **System**, and sidebar themes require **Light**.
- Toggle **Achievements and XP** and **Generate chat titles**.
- Set **Resume recent chats** in minutes, or `0` for the start screen.
- Choose **Steer** or **Queue** under **Follow-up behavior**.
- Use Ctrl+Enter for the other behavior once.
- Select **Time Zone** and **Language**.
- **About** shows app and framework versions.
- **Credits and licenses** lists bundled software notices.
- **Delete Conversations** permanently removes saved chats after confirmation.

> **Note:** changing Language reloads the translated interface.

## Protect automatic tasks

- **Skip scheduled tasks on low battery** starts off.
- Set **Battery threshold (%)** from 1 to 100, default 10.
- Skips apply below the threshold only when the server computer is unplugged.
- The disabled control explains unavailable battery detection.
- Saved protection stays enabled when detection becomes unavailable, and unknown readings permit execution.
- Skips notify you and retain the next recurring occurrence.
- Use **Run now** to retry a skipped task.
