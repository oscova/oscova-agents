# Create task webhook API key

Create a token for an external caller to trigger selected tasks.

- Enter an **API key name**.
- Enter **Allowed task slugs, comma separated**.
- Copy each complete owner-qualified slug from its task endpoint.
- An empty allowed-slug list authorizes no tasks.
- Click **Create API key**, then copy the token shown by the parent screen.

> **Note:** The token is shown only once. Keep it secret.
