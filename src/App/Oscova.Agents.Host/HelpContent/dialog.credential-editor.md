# Save credential

Create or update a secret that providers and integrations can reference.

- Give a free-form credential a unique **Name** and optional **Description**.
- Built-in integration names are fixed.
- **Enter a value** stores an encrypted secret.
- **Use an environment variable** stores only the variable name, where available.
- Suggestions list variable names visible to the running server.
- Required fields need a value or variable name.
- **Save Credential** applies the entry.
- Confirm any requested interruption of affected work.

> **Note:** Stored secrets are never displayed again. Leave an existing stored value blank to preserve it.

> **Note:** Stored values require an unlocked vault. A saved variable name does not prove that variable has a runtime value.
