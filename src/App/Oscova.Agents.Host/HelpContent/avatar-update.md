# Avatar Engine installation and updates

Updates apply to the computer running this harness. A renderer on another computer is managed separately.

Release checks run automatically. Refresh checks both the harness and Avatar publication again. The bell saves each newly announced release, including when this computer has no Avatar Engine installed.

Choose **Install Avatar** for a first installation or **Update Avatar** for changed installed content. Review the published version and download size, then confirm installation. A running managed local engine stops and restarts using its previous binding. A stopped engine stays stopped.

The installation continues after you close this dialog. Open it again to see progress or the result. Failed downloads or verification preserve the valid installed engine. If files were installed but relaunch failed, start the engine from Avatar settings.

Local installation requires Windows and the App launcher. Start the harness with `oscova start` for dashboard Avatar management. On a Windows renderer, `oscova avatar install` installs the server's current publication.
