# GitHub skill search token

Set the optional shared GitHub token used for authenticated skill repository access.

- Enter a **Personal Access Token**.
- Leave the token blank to preserve an existing token.
- Click **Save** to apply it.
- **Clear** asks for confirmation before removing the token.
- **Cancel** returns without saving edits.

> **Note:** The stored token is never shown again and needs the protecting operator's vault unlocked after restart.
