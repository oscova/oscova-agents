# File history

Compare the current file with a saved restore point before restoring it.

- Select a dated restore point to load its comparison.
- Each eligible file retains up to 30 restore points.
- **Current** shows the text from the editor when you opened History.
- **Restore** becomes available after a restore point loads.
- Confirm restoration to replace the saved file and reload the editor.

> **Note:** Restoration backs up the current file when possible. Unsaved editor text is replaced after a successful restore.
