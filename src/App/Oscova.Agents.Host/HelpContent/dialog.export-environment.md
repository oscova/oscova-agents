# Export environment

Download an encrypted backup of restorable app data.

- Enter a **Passphrase** to enable **Start Export**.
- Click **Start Export** to download the `.oscb` backup.
- Keep the backup and passphrase safely.
- **Cancel** returns without exporting.

> **Note:** This passphrase protects the backup only. It is separate from your Account Password and Vault Password.

> **Note:** The backup includes users, chats, settings, credentials, plugins, and user-folder logs. Models, voices, shared system logs, pending restores, machine-local authentication keys, and the shared skill registry cache are excluded.
