# Create file or folder

Add one file or folder inside the current Files location.

- Enter a single valid **Name**.
- Files must use `.md`, `.txt`, `.json`, `.yaml`, `.yml`, `.csv`, `.xml`, or `.enc`.
- **Create** becomes available when the name and file extension are valid.
- **Cancel** leaves the current location unchanged.

> **Note:** Enter a name, not a folder path.
