# Add project

Choose where a project chat works by selecting a computer and an existing folder.

- Select a connected, available **Device**.
- The operator can choose **This server**.
- Regular users need Projects permission and an available enrolled device.
- Enter a **Name** of up to 100 characters and the existing folder path.
- Click **Add Project** to create the project.
- **Cancel** leaves your project list unchanged.

> **Note:** The folder must exist on the selected computer. Adding a project does not copy its files.
