# Pair Avatar Engine

Authorize this connection using the code shown by the running Avatar Engine.

- Enter the six-digit **Pairing code** shown by the engine.
- Review the fixed **Access mode** before clicking **Pair**.
- **Shared** permits other paired clients.
- **Exclusive** blocks them until the engine restarts.
- Watch the countdown while entering the code.
- If it expires, close the dialog and select **Connect** again for a new code.
- **Cancel** abandons this pairing attempt.

> **Note:** Successful pairing is reused after either program restarts unless pairing is reset.
