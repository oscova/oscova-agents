# Message layout

Position the message box within the selected Avatar screen resolution.

- Drag the message box to move it.
- Resize it from a corner.
- Enter **Left**, **Top**, **Width**, and **Height** for exact percentages.
- Keep the box inside the screen, with width and height at least 1%.
- **Save** returns this layout to the Avatar settings draft.
- **Cancel** discards the layout edits.

> **Note:** Use Apply Message Box on the parent screen to preview the draft on the running engine. Save Settings keeps it for later.
