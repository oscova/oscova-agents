# Choose picture or wallpaper

Select a built-in image or upload one for the picture or wallpaper you are changing.

- Choose a built-in image or **Upload your own**.
- Compare **Current** and **Selected** before applying.
- Uploads must be PNG, JPEG, or WebP.
- Pictures allow up to 2 MB.
- Wallpapers allow up to 10 MB, with 1920 by 1080 recommended.
- **Use this picture** or **Use this wallpaper** saves the selected image immediately.
- **Cancel** keeps the current image.

> **Note:** Save a new agent before changing its picture. Image changes save separately from profile or settings forms.
