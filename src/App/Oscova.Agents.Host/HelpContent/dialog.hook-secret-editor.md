# Save outbound hook secret

Store the secret used by an outbound HTTP hook header.

- Enter **Secret name**, **Secret reference key**, and an optional **Description**.
- Enter **Secret value** when creating a secret.
- Leave the value blank when editing to preserve the stored value.
- **Save secret** applies the entry.
- **Cancel** keeps the existing secret.

> **Note:** Select this saved secret from the hook editor's Secret headers.
