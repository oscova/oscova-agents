# Edit instructions

Edit the instruction text opened by the current screen.

- For a seeded instruction, choose **Use Default**, **Add to Default**, or **Replace Default**. Use Default displays the supplied instruction. The other modes edit your custom text and offer a collapsible default reference.
- Add to Default supplies the default followed by your text. Replace Default supplies only your text. Decide any priorities within your own instructions.
- User-created agents and tasks have a plain text editor.
- Click an available variable chip to insert it at the cursor.
- **Restore default** asks for confirmation before clearing your custom text and switching to Use Default. Click **Save** to apply it. **No** or dismissing the confirmation preserves your edits.
- **Save** applies the text to the screen that opened this dialog.
- **Cancel** returns without applying your edits.
- A save error keeps the dialog open so you can correct or retry it.

> **Note:** Agent and task editors update their parent form's draft. Save that form separately to keep the changes. Cancelling the parent preserves the saved instruction.

> **Note:** Shared instruction files must stay within the 512 KB editor limit. Saved changes apply to later runs.
