# Find plugins online

Search NuGet.org for OscovaPlugin packages and review them before installation.

- Enter a package name and click **Search**, or press Enter.
- Open **Details** to inspect description, publisher, project, and license.
- Review any model-plugin hardware requirements and observations before installing. Unknown metadata or unavailable detection still permits a choice. Runtime support remains unverified until a saved provider's Test succeeds.
- **Install or update** downloads and validates the package and its runtime dependencies immediately. The button shows **Installing...** while it works and **Installed** when the package is ready.
- A plugin that cannot be installed here shows why, such as **Requires a newer Oscova** or **Prerelease only**, and its install button is off.
- Use **Retry** after correcting a failure.
- **Replace plugin** requires confirmation when another package claims an installed plugin's identity.
- Return to Plugins to confirm **Load On Next Restart**, save, and restart.

> **Note:** Verified identifies a NuGet search badge, not code safety. Enabled plugins run with Oscova's permissions.

> **Note:** A running plugin's replacement activates after restart. Finish a pending restart before switching its edition again.
