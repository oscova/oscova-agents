# Connected-account providers

Configure the shared sign-in applications used by available connected-account providers.

- Enter the provider's **Client ID** and **Client Secret**.
- Leave an existing secret blank to preserve it.
- Clear the client ID to disable that provider.
- Save each provider separately.

> **Note:** These settings configure the shared application. Each user connects their own account separately.

> **Note:** Stored shared secrets need their protecting operator's vault unlocked after restart.
