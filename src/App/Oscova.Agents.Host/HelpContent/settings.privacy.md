# Privacy

Keep runs local and sign an idle browser out.

> **In plain terms:** offline mode limits where runs send data. Automatic sign-out limits idle access.

## Keep runs offline

- Enable **Keep agent runs offline**.
- Save to apply changes, or reset to discard them.
- Local models, local tools, loopback services, and LAN endpoints remain available.
- Cloud providers, Internet tools, public requests, cloud speech, and cloud embeddings are blocked during runs.
- **Live effect** shows affected Internet tools and configured cloud providers.

> **Note:** Discord, Telegram, and Slack still use external servers. Stop them separately.

## Sign out an idle browser

- Choose **Off**, **5 minutes**, **15 minutes**, or **30 minutes** under **Automatic sign-out**.
- Mouse, touch, keyboard, scrolling, and submitted messages count as activity.
- Activity in another open Oscova tab for your user keeps this browser profile signed in.
- Other profiles and devices keep independent idle clocks.
- Automatic sign-out discards incognito chats, just like ordinary logout.

> **Note:** signing out does not lock encrypted data or cancel running tasks.
