# Model budget reached

Review the spending-limit notice before deciding whether this operation can continue.

- Read the notice for the next reset time.
- **Cancel** leaves the operation blocked.
- **Continue anyway** appears only when you own the provider and may override this operation.

> **Note:** Continuing does not remove the saved limits. Other consumers cannot override the owner's budget.
