# Import agent

Add an agent from an exported package without replacing an existing agent.

- **Choose Agent File** accepts one `.oscagent` package up to 5 MB.
- Use **Name (optional)** to replace the package's name.
- Leave the name blank to retain it, with a number added if needed.
- Click **Import** after selecting the file.
- **Cancel** returns without importing.

> **Note:** Chats, memory, and private agent notes are not included.

> **Note:** Unavailable references and sub-agent links are removed. The import result reports removed references.
