# Chat provider details

Inspect the saved connection, capabilities, prices, and chat defaults for one provider.

- **Default** and **Fallback** identify this provider's role.
- Review **Model ID**, **Base URL**, and the linked **Credential**.
- Review the configured context size and image or thinking capabilities.
- Prices show saved USD estimates per million tokens.
- **Last Test** reports the latest connectivity or isolated inference check. Only observed runtime evidence can establish GPU offload, and a past result does not prove current spare memory.
- **Chat Options** shows saved defaults, with **Auto** for unspecified values.

> **Note:** This view does not test the connection or edit the provider.
