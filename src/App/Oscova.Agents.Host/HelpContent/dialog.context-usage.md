# Context usage

Review how much space your conversation or agent instructions need in the selected model.

> **In plain terms:** context is the text and other material the model can consider at once.

- **Used** estimates input already occupying the context window.
- **Free space** estimates room for more input.
- **Reserved output** leaves space for the model's answer.
- **Context window** is the configured model capacity.
- An agent preview shows its instruction and context contributions.
- Expand instructions and tools to inspect their contributions, including skill discovery and loader tools.
- Unpinned searchable tools are excluded from the initial total, and full skill contents load later.
- Configure a context-window size in Model Providers if usage is unavailable.

> **Note:** These are estimates, not the provider's final token counts. Viewing them does not change the conversation.
