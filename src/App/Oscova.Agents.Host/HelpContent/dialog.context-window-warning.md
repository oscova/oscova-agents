# Context window warning

Decide whether to send a draft estimated to exceed the selected model's context window.

- Review **Estimated input**, **Reserved output**, and **Estimated overage**.
- Use **Estimate breakdown** to identify instructions, history, attachments, tools, or draft text consuming space.
- **Cancel** returns to the composer so you can shorten the input.
- **Continue anyway** sends the draft despite the warning.

> **Note:** Continuing may fail, truncate context, or lose earlier details.
