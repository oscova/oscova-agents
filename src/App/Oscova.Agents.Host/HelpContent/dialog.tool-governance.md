# Tool policy

Set this tool's network classification and optional call limit for your account.

- Check **Qualified Name** and **Server** to confirm the tool.
- **Use declared scope** keeps the tool's original network classification.
- Choose another **Network access** value only to match its actual behavior.
- **Limit calls** enables a maximum of 1 to 1,000,000 calls.
- The limit uses a fixed 24-hour window.
- Click **Save** to apply the policy.
- **Cancel** preserves it.

> **Note:** Saving does not select the tool for an agent. Network classification does not sandbox a host process.
