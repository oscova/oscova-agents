# Edit user

Update one account's profile, sign-in settings, and execution permissions.

- **Save profile** applies username, email, and full-name edits. Usernames use lowercase.
- **Reset password** changes another user's Account Password.
- Change your own password through Your Profile.
- **Set PIN** or **Change PIN** requires matching PINs of 6 to 64 digits.
- **Clear PIN** removes ordinary PIN sign-in and suspends any duress PIN.
- Two-factor-enabled accounts cannot use PIN sign-in.
- For regular users, set Projects, Workspace shell, Project shell, and Shared folder permissions independently.
- **Shared folder** lets the user and their agents use the folder shared by permitted users.
- Project shell also requires Projects.
- **Save changes** applies the execution permissions.

> **Note:** Permission removal blocks new affected calls and requests cancellation of affected running work. Completed changes remain.
