# Task details

Review one task's configuration, latest status, and recent executions.

- Review **Agent**, **Model Provider**, **Schedule**, and **Instruction**.
- **Recent Executions** includes the current live run when one exists.
- **Inspect** opens a run's stored messages when available.
- **View all** or **Runs** opens the full run history.
- **Edit** opens the task editor.
- **Run now** is available only when the task is enabled and idle.
- If the task deletes itself while details are open, **Deleted task** appears. The loaded result and **Inspect** remain available, while **View all**, **Runs**, **Edit**, and **Run now** are disabled.
