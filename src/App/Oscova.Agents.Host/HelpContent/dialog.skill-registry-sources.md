# Skill sources

Choose the GitHub repositories searched by Find skills online.

- **Search method** applies to everyone using this host after you click **Save**.
- **GitHub API** searches repository metadata without downloading files and is the default.
- **Local repository downloads** downloads entire repositories, including scripts, to the computer running Oscova.
- **Add source** creates another repository row.
- Enter **Owner**, **Repository**, and **Branch**.
- Use **Skills folder (optional)** to search one folder and its subfolders.
- Leave the folder blank to search the whole repository.
- The repository link opens the configured branch in a new tab.
- Remove a row to stop searching that source.
- Click **Save** to apply your sources and search method.
- **Cancel** discards edits.

> **Note:** The operator can configure a shared GitHub token for authenticated repository access.
