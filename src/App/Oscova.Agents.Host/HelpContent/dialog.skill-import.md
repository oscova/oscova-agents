# Import skill

Add one skill from a document or packaged archive.

- **Choose Skill File** accepts a `SKILL.md` document or `.zip` package up to 10 MB.
- Expanded archive contents must fit within 30 MB.
- Archives may include scripts, references, and assets.
- Click **Import** after selecting a file.
- Review any **Import warnings**.
- Assign the imported skill to an agent before expecting it to use it.

> **Note:** Review bundled scripts before allowing execution.
