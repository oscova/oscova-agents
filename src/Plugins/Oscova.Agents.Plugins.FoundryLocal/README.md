# Oscova Foundry Local Provider

Adds Microsoft Foundry Local model discovery, download, and inference to Oscova Agents without placing the native runtime in the main application package.

Install and enable the plugin, restart Oscova, then add a `FoundryLocal` model provider. Fetch the catalog, select an alias, review its license, and download it before saving the provider. No API key is required.

Supported platforms are Windows x64, Linux x64, and Apple Silicon macOS. Intel macOS is not supported by Foundry Local.

See [Model providers](https://oscova.ai/docs/articles/user-guide/concepts/model-providers.html) for provider setup.
