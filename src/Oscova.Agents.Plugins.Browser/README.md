# Oscova Browser

An Oscova Agents plugin that provides visible browser navigation, page reading and interaction, shared between you and your agent in the chat workspace. The host owns the viewer and chat authorization. Playwright and its driver install separately from the Oscova application. Matching Chromium downloads on first use.

Regular chats share a separate profile for the same user. Incognito chats use isolated temporary contexts. The profile is outside Vault encryption. This is not the user's personal browser profile. Native password-manager windows, operating-system authentication and full browser menus are unsupported. Desktop interaction is supported, while phone support is viewing only.

See [Browse a website together](https://oscova.ai/docs/articles/user-guide/chat-and-agents/main-agent-chat.html#browse-a-website-together) for setup, file transfers and interaction limits.
