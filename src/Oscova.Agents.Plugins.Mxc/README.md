# Microsoft MXC execution for Oscova

Provides native operating-system containment for shell commands and bundled skill scripts through Microsoft.Mxc.Sdk. The operator selects Microsoft MXC in Settings > Agents & AI > Execution. Existing workspace grants and sandbox network permission apply.

The package contributes its execution provider and a compiled Razor settings component through Oscova's plugin contracts. It uses the host theme and supplies no stylesheet.
