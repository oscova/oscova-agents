# Oscova Docker Execution

An Oscova Agents plugin that runs agent shell commands and bundled skill scripts inside Docker, with only the granted folders mounted.

Choose this plugin during CLI installation, or install and enable it later in Settings > Plugins, then restart Oscova. Select Docker in Settings > Agents & AI > Execution. Operators manage the shared image from the same page. Docker Desktop or Docker Engine must be installed on each device that executes commands.

See [Execution](https://oscova.ai/docs/articles/user-guide/settings-and-admin/execution.html) for setup and limits.
